Services

Each job starts with a diagnostic read of the engine and the ECU, so the work done matches what the vehicle actually needs.

Engine & ECU diagnostics

Find the root cause, not just the fault code.

  • Active and inactive fault code reading and interpretation
  • Live data, derate and low-power troubleshooting
  • Sensor, actuator and wiring checks
  • Written diagnostic report

ECU programming

Flash and configure engine control modules.

  • Calibration updates and reflash
  • Replacement / used ECU programming and setup
  • Matching ECU to engine serial and vehicle data
  • Module recovery after a failed flash

Return to stock

Restore the original factory calibration.

  • Reflash to the OEM calibration for the engine
  • Backup of the existing ECU file before any change
  • Verification after programming

Performance calibration

More power and torque within the engine's limits.

  • Power and torque optimization
  • Fuel economy oriented calibration
  • Tuned for the engine, transmission and use of the truck

Injectors

Correct fueling after injector replacement.

  • Injector trim / calibration code programming
  • Cylinder balance and cutout tests

Parameter adjustments

Customer-programmable settings.

  • Road speed and cruise control limits
  • Idle shutdown and idle speed settings
  • Tire size, gear ratios and other vehicle parameters

Engines we work with

Heavy-duty diesel engines for trucks, buses and equipment.

Terms

Quotes and payment

Every job is quoted in advance based on the engine and the work requested. Work starts once the quote is accepted and payment is confirmed.

Customer responsibilities

For remote service the customer provides a laptop with internet access, a compatible diagnostic adapter and a stable battery supply during programming. The customer is responsible for the mechanical condition of the vehicle.

Refunds

If we cannot complete the service for reasons on our side, the payment is refunded in full. Once a service has been delivered it is not refundable, but we will work with you to resolve any issue with the work performed.

Privacy

Vehicle data and ECU files are used only to perform the service and are not shared with third parties.
